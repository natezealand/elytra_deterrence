# genius deterrence
this datapack checks every tick for if any players are wearing an elytra in their chest slot,
if they are they are instantly /kill-ed !

i made this for my personal server after the members voted to ban elytra usage.

# install instructions
to install this datapack simply download the source code, extract the zip archive and put it in your datapack folder.
to check if the mod is active and working do /reload - and a message from the datapack should pop up!
